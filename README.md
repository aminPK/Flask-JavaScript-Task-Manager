# Flask JavaScript Task Manager

A full-stack task management application built with Python Flask, JavaScript, HTML, and CSS.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear all completed tasks
- Save tasks using a JSON file
- Communicate with a Flask backend through REST API endpoints
- Simple and modern user interface

## 🛠️ Technologies Used

- Python
- Flask
- Flask-CORS
- JavaScript
- HTML5
- CSS3
- JSON

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/aminPK/Flask-JavaScript-Task-Manager.git
```

2. Open the project folder:

```bash
cd Flask-JavaScript-Task-Manager
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start the Flask application:

```bash
python app.py
```

5. Open your browser:

```text
http://127.0.0.1:5000
```
